## เกี่ยวกับระบบ

ระบบนำทางอัตโนมัติสำหรับต้นแบบรถยนต์ไร้คนขับแบบ Ackermann steering 
(ROS 2 + Nav2 + ESP32-S3)

รถต้นแบบใช้กลไกบังคับเลี้ยวแบบ **Ackermann steering** (บังคับเลี้ยวด้วยล้อหน้า 
เหมือนรถยนต์ทั่วไป) ไม่ใช่ระบบ Differential drive จึงไม่สามารถหมุนอยู่กับที่ได้ 
ต้องมีการเคลื่อนที่ไปข้างหน้า/ถอยหลังควบคู่กับการเลี้ยวเสมอ ระบบนำทางจึงถูกปรับแต่ง
ให้เหมาะกับข้อจำกัดนี้ เช่น การปิด `use_rotate_to_heading` และเลือกใช้ 
Reeds-Shepp motion model ในการวางแผนเส้นทาง

## เทคโนโลยีที่ใช้

- ROS 2
- Nav2 (Navigation stack)
- SLAM Toolbox
- ESP32-S3 (micro-ROS)
- MPU6050 (IMU)
- TDLiDAR x3
